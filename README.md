## 페이지 구조

```
main.container
├── aside.sidebar           ← 좌측
│   ├── 프로필 카드 (아바타 · 인사 · 이름 · 슬로건)
│   └── 액션 버튼 (연락하기 / 공유하기)
└── div.content             ← 우측
    ├── 탭 메뉴 (👤 소개 / 🥊 나의 취미)
    ├── [소개 탭]
    │   ├── 기본 정보 카드 (직업 · 음식 · 취미 태그)
    │   ├── 최근 읽은 책 카드 (표지 + 제목)
    │   └── 특이사항 갤러리 (사진 1 + 이모지 카드 4)

        ├── 복싱 카드
        └── 뮤지컬 카드
footer (© 2026 이병호)
```

## 디자인 시스템

디자인 토큰은 `gs-retail.md`(우리동네GS design.md)를 기준으로 합니다.

### 색상

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--primary-dark` | `#1E2530` | 본문 텍스트, 1차 버튼 |
| `--signature-cyan` | `#00D4EA` | 브랜드 포인트, 포커스 테두리 |
| `--neutral-50` | `#F4F5FB` | 페이지 배경 |
| `--neutral-200` | `#D6D9E1` | 카드 테두리 |
| `--neutral-600` | `#515160` | 보조 텍스트 |
| `--navy-deep` | `#001C43` | 1차 버튼 눌림 상태 |

### 형태 · 타이포그래피

- **폰트**: Pretendard Variable
- **카드 모서리**: 18px / 버튼·태그는 필(pill) 형태(999px)
- **그림자 없음**: 그림자 대신 테두리와 면 분리로 깊이 표현
- **좌우 여백**: 16px
- **섹션 제목**: 18px / 700

## 반응형 레이아웃

| 화면 | 레이아웃 |
|------|----------|
| **모바일** (768px 미만) | 카드를 한 열로 쌓음, 갤러리는 2열 |
| **데스크톱** (768px 이상) | 최대 폭 960px, 좌 1 : 우 2 비율의 2열 그리드. 좌측 사이드바는 스크롤해도 고정(sticky) |

## 접근성

- `lang="ko"`, `meta description` 지정
- 각 섹션에 `aria-labelledby`로 제목 연결
- 이미지마다 `alt` 대체 텍스트 제공
- 프로필 사진을 못 불러오면 이니셜 '이'로 자동 대체
- 탭 메뉴는 `role="tab"` / `tabpanel` 구조, ←/→ 방향키로도 전환 가능
- 키보드 포커스 시 청록색 외곽선 표시 (`:focus-visible`)
- `prefers-reduced-motion` 설정 시 전환 효과 제거
